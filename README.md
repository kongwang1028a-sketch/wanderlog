# 旅遊足跡

在世界地圖上記下每一次出國。到過的城市會標出範圍，停留的位置升起旗幟。點開旗幟可以看到那趟旅程的路線、當地常被提到的景點，以及你自己的照片或雲端相簿連結。

資料只存在這台瀏覽器：旅程存在 localStorage，上傳的照片存在 IndexedDB。換電腦或清除網站資料前，請先按「匯出」。

## 可以做的事

- 新增旅程：名稱、出發與回程、依順序排列的停留城市
- 貼上簡短大綱，或含每天、航班、住宿的完整行程表，自動讀出日期與城市並匯入停留點
- 一次貼上很多趟回憶。一行寫年份和城市，例如「2019 朱諾、黃刀鎮」，不必找出每天的行程
- 從手機照片的拍攝定位整理旅程。拍照時需要有開定位；沒有定位的照片會略過
- 放入 Google 時間軸匯出的 JSON，或 GPX 軌跡。到 [Google Takeout](https://takeout.google.com) 匯出「位置紀錄」，可以一次選很多個月的檔案。日常待很久的城市會先拿掉
- 每趟可以記下飛機機型、航段和旅館名稱。貼上完整行程表時，旅館和航班編號也會一併讀出
- 搜尋城市，或直接在地圖上點一個位置
- 點旗幟查看路線與知名景點。旗上寫的是去過的年份，滑過看得到旅程標題
- 上傳照片（會先縮小再保存），或貼上 Google 雲端、iCloud 的分享連結。從照片定位匯入時，也可以一併留下每趟最多 8 張
- 匯出、匯入 JSON，方便換瀏覽器時帶走
- 分享網址給朋友。對方會有自己的空白地圖；同一台裝置可以建立不同的足跡本

Google 雲端與 iCloud 的相簿通常不能直接嵌在網頁裡。連結會留在這趟旅程上，之後用新分頁打開。

## 本地執行

```bash
npm install
npm run dev -- -H 0.0.0.0 -p 43123
```

打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

地圖地名使用 Google 的繁體中文圖磚，需要網路才能看到。紅色範圍大約是城市方圓 15 公里；只記到國家、還沒有城市的行程只顯示旗幟。

## 讓別人看到我的旅程

`public/data/footprints.json` 是網站上的公開足跡。別人打開網址時會看到這份檔案裡的旅程。你瀏覽器裡另外建立的足跡本不會自動上傳。

1. 在網站按「分享」，再按「下載公開足跡」。
2. 用下載的 `footprints.json` 覆蓋 `public/data/footprints.json`。
3. 提交並推上 GitHub 的 `main`。
4. 到該存放庫的 Settings → Pages → Build and deployment，Source 選 GitHub Actions。
5. Actions 完成後，網址是 `https://你的帳號.github.io/存放庫名稱/`。存放庫名稱若是 `帳號.github.io`，網址則是 `https://帳號.github.io/`。

GitHub Pages 是靜態網頁，公開網址不使用進入密碼。存放庫需要是 Public，免費方案才會提供 Pages。

## 放到 GitHub Pages

上面的步驟會一併把網站發布到 GitHub Pages。公開檔已經包含美加極光海陸旅行團，以及橫濱、鎌倉。你之後新加的旅程，要再下載一次公開足跡並覆蓋檔案，朋友重新整理才看得到。

## 放到 Vercel

若要設定進入密碼，改用有伺服器的主機。

1. 到 [Vercel](https://vercel.com) 用該存放庫建立專案，框架選 Next.js。
2. 在 Vercel 的 Environment Variables 新增 `SITE_PASSWORD`，值是你要給朋友的進入密碼。留空則任何人拿到網址都能打開網站，並看到公開足跡。各自另外建立的足跡本仍然只留在自己的瀏覽器。
3. 部署完成後，把 `https://` 開頭的網址傳給朋友，密碼另外傳，不要寫在網址裡。

改密碼之後重新部署，舊的進入狀態會失效。想改回公開，刪掉 `SITE_PASSWORD` 再部署一次。

自己的伺服器也可以：

```bash
SITE_PASSWORD=約好的密碼 npm run build
SITE_PASSWORD=約好的密碼 npm start
```

設了密碼之後，搜尋引擎會被要求不要收錄這個網站。
